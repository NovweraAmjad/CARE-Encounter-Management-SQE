# Test Data

All data is **synthetic**. No real patient information is used anywhere.

## 1. Database seed (shared by every test level)

The CARE backend seeds the database with its own fixture command:

```bash
docker compose -f care/docker-compose.yaml -f care/docker-compose.local.yaml \
  exec backend python manage.py load_fixtures
```

`care/care/fixtures/scripts/default_fixtures.py` creates:
- facility "FACILITY WITH PATIENTS"
- 10 Faker-generated patients, each with one encounter
- departments, locations
- the role accounts used by the tests:

| Account | Role | Used by |
|---|---|---|
| `care-doctor` | Doctor (member of the facility's Administration department) | all workflow tests, k6 |
| `care-volunteer` | Volunteer (no facility membership) | authorization checks, E2E-ENC-010 |

The fixture password is printed by `load_fixtures` (CARE's documented local credentials). Reset between runs: see [`../README.md`](../README.md#reset-between-runs).

## 2. Per-test data

- **Backend unit/integration tests** create their own records inside a Django `TestCase` transaction (`CareAPITestBase` + `model_bakery`). Each test rolls them back.
- **Browser and security tests** create the open encounters they need through the API as `care-doctor` and cancel them afterwards (`testing/e2e/helpers.ts`, `testing/e2e/specs/use-cases.spec.ts`).

## 3. Generated data (OpenAPI → equivalence classes + 3-point BVA)

Generated by `testing/generators/encounter_data_generator.py` from the OpenAPI specs, and consumed by the API tests:

| File | Source spec | Content |
|---|---|---|
| `generated-cases-v1.json` | `testing/openapi/encounter-openapi.yaml` | Valid/invalid classes per input; BVA: active limit 4/5/6, identifier length 99/100/101 |
| `generated-cases-v2.json` | `testing/openapi/encounter-openapi.v2.yaml` (two constraints changed) | BVA: active limit **2/3/4**, identifier length **11/12/13** |
| `generated-invalid-and-restart.json` | generator | One invalid value per input; restart-window age boundaries |

Regenerate with the backend container running:

```bash
docker cp testing/. care-backend-1:/tmp/care_testing/
docker exec care-backend-1 bash -lc 'cd /app && PYTHONPATH=/tmp:/app DJANGO_SETTINGS_MODULE=config.settings.test \
  /.venv/bin/python manage.py test care_testing.generators'
```

This also rewrites `encounter-openapi.v2.yaml` and `testing/evidence/two-constraint-regeneration.json`.
